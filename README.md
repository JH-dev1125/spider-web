# Web Runner

빌딩 사이를 줄(웹)로 스윙하며 달리는 브라우저 게임. 설치·빌드 없이 파일만 열면 돌아간다.

## 1. 실행

```
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. (`index.html`을 더블클릭하면 모듈이 막혀서 안 돌아가니 꼭 서버로 연다.)

## 2. 조작

키보드 (왼쪽 / 오른쪽 벽의 위·가운데·아래로 줄을 쏜다)

| | 위 | 가운데 | 아래 |
|---|---|---|---|
| 왼쪽 | Q | A | Z |
| 오른쪽 | E | D | C |
| 정면 위 | | W | |

- 누르면 즉시 거미줄 → 누르고 있는 동안 스윙 → 떼면 날아감.
- 줄 두 개: 왼손(Q/A/Z)과 오른손(E/D/C)은 각자 줄을 하나씩 잡는다. Q와 E를 함께 누르면 줄 두 개로 스윙하고, 한쪽 키만 떼면 그 줄만 풀린다. 같은 손 키를 다시 누르면 그 손의 줄만 바뀐다.
- W: 길 한가운데를 따라 정면 위로 가파르게 쏜다. 빈 손으로 쏘고, 두 손이 다 줄을 잡고 있으면 먼저 잡은 줄을 바꾼다. 길 위를 가로지르는 크레인 팔이나 구름다리에 줄을 걸 때 쓴다. 위에 아무것도 없으면 빗나간다.
- 빌딩 중간의 테라스 층(기둥만 있고 벽이 없는 층)에는 줄이 붙지 않고 빠져나간다. 그 위아래 층은 붙는다.
- 물리 엔진(cannon-es)으로 움직인다. 떼는 순간의 속도가 그대로 유지되니, 최저점을 지나 위로 올라갈 때 떼면 멀리 날아간다.
- 너무 오래 잡고 있으면 진자처럼 뒤로 되돌아간다.
- Space / 손 당기기 (줄이 붙어 있을 때): 새총. 그 순간 줄을 놓고, 진행 방향(줄 쪽으로 조금 기울여)으로 약 20 m/s를 더 받아 튀어 나간다. 줄이 두 개면 두 줄 방향을 합친 쪽으로 기울이고 둘 다 놓는다. 한 번 누르면 한 번, 0.6초 쿨다운. 줄이 없으면 아무 일도 없다.
- Space / Enter / 손바닥 1초: 시작(아주 높은 옥상 끝에서 머리부터 다이빙해 출발, 줄을 쏘면 다이빙에서 빠져나온다), 착지 포즈가 멈춘 뒤 다시 하기.
- 빠르게 빌딩 옆면에 부딪히면 잠깐 벽을 타고 달린 뒤 저절로 벽을 차고 뛰어오른다.
- 위로 올라가면서 벽에 부딪히거나, 같은 벽 높은 곳에 붙은 줄로 새총을 쏘면 벽을 수직으로 달려 올라간다(최대 2.5초). 옥상 끝에 닿으면 난간을 넘어 웅크려 앉고, 못 닿으면 뒤로 차고 떨어진다.
- 줄 없이 옥상에 있으면 달린다. 2초 동안 아무 입력이 없으면 멈춰 서서 도시를 바라본다. 줄을 쏘면 다시 달린다.
- 줄 없이 날 때는 공중 동작(구르기, 다이빙, 발레 자세 등 26가지)을 쉬지 않고 이어서 한다. 줄을 쏘면 바로 멈춘다.

도시와 모퉁이 돌기

- 도시는 바둑판 모양이다. 120~200 m마다 교차로가 있고, 블록의 네 모서리마다 높은 모퉁이 빌딩이 서 있다.
- 왼쪽(Q/A/Z)·오른쪽(E/D/C)과 줄이 날아가는 "앞"은 지금 달리는 길이 기준이다. 길을 꺾으면 방향도 같이 돈다. 손동작도 같다.
- 꺾는 법: 교차로에 다가가면서 꺾을 쪽 모퉁이 빌딩(교차로 바로 앞, 그쪽 벽)에 줄을 쏘고 잡고 있는다. 모퉁이를 끼고 돌아 옆 길로 날아가게 된다.
- 교차로 안에서 옆 길 방향 속도가 수평 속도의 60%를 넘으면 그 길이 새 진행 방향이 된다. 카메라가 부드럽게 따라 돌고(초당 최대 120도), 그때 떼면 새 길을 따라 날아간다.
- 블록 안쪽으로는 못 들어간다. 낮은 지붕 위나 빈 땅을 가로지르는 대각선 지름길은 없고, 움직임은 늘 길을 따라간다.
- 줄은 건물을 통과하지 않는다. 날아가는 줄은 처음 닿는 건물에 붙는다. 잡고 있는 줄이 건물 모서리에 걸리면 그 모서리에 감겨서 거기를 축으로 돈다. 반대로 돌아 나오면 풀린다. 4번 넘게 감기면 줄이 끊어진다.
- 점수(m)는 길을 따라 움직인 거리다. 꺾은 뒤에도 계속 쌓인다.

웹캠 손동작 (제목 화면에서 `H`로 켠다. 키보드도 같이 동작)

- 발사 자세: 검지와 새끼손가락을 펴고, 중지와 약지는 접는다.
- 오른쪽 아래 미리보기(거울처럼 좌우가 뒤집힌 화면)를 세로로 세 칸으로 나눈다. 손이 왼쪽 칸이면 왼쪽, 오른쪽 칸이면 오른쪽, 가운데 칸이면 W(정면 위, 빈 손). 어느 손을 쓰는지는 상관없다.
- 두 손을 다 발사 자세로 하면 줄 두 개. 각 손은 자기 칸의 줄만 잡고, 그 손을 풀면 그 줄만 풀린다.
- 같은 미리보기에서 손 높이(위/가운데/아래 세 구간)로 줄을 쏘는 높이를 고른다.
- 줄 당기기: 발사 자세를 유지한 채 손을 몸 쪽으로 빠르게 당긴다(카메라에서 멀어져 손이 작아 보이면 인식). 상태 표시에 `당기기!`가 뜬다.
- 검지·새끼 펴면 발사, 유지하면 스윙, 풀면 날아감.
- 손바닥을 펴고 1초 유지하면 시작 / 다시 하기.

웹캠은 HTTPS 또는 localhost에서만 동작한다. 영상은 이 PC 안에서만 처리되고 밖으로 나가지 않는다.

## 3. 배포 (GitHub Pages)

1. GitHub에서 빈 저장소를 만든다.
2. 이 폴더에서:
   ```
   git remote add origin https://github.com/<아이디>/<저장소>.git
   git push -u origin main
   ```
3. 저장소 Settings → Pages → Source: Deploy from a branch → Branch `main`, `/ (root)` → Save.
4. 1~2분 뒤 친구에게 줄 주소: `https://<아이디>.github.io/<저장소>/`

Pages는 HTTPS라서 친구들도 웹캠 손동작을 쓸 수 있다.

## 4. 손동작 시험판

`/spike/hand.html` (로컬이면 `http://localhost:8000/spike/hand.html`). 웹캠 손 인식이 내 환경에서 잘 되는지 따로 확인하는 페이지.

## 5. 테스트

```
node --test tests/*.test.js
```

Node 22.15 이상 필요. (`npm test`도 같은 명령)

디버그 주소: `?autoplay`(자동 조종), `?autoplay&autoturn=R`(교차로마다 오른쪽으로 꺾기, `L`·`alt`도 됨), `?seed=8`(같은 도시 고정), `?t=10`(10초 빨리 감기).

## 6. 수정 가이드

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 속도·중력·줄 길이·난이도 등 모든 숫자, 색, 키 배치 | `src/config.js` |
| 캐릭터 모양·포즈 | `src/character.js` |
| 빌딩·배경 그리기, 카메라 | `src/render.js` |
| 줄 조준 / 물리 엔진 연동(줄·충돌) | `src/web.js` / `src/player.js` (엔진: `vendor/cannon-es.js`) |
| 바둑판 도시·모퉁이 빌딩·구조물 생성(난이도, 막힌 구간 방지), 블록 출입 금지 | `src/world.js` |
| 지금 달리는 길(진행 방향·좌우 기준) | `src/street.js`, 길 바꾸기는 `src/game.js` |
| 줄이 건물 모서리에 감기기·풀리기·끊어지기 | `src/rope.js` |
| 점수 | `src/score.js` |
| 줄 발사, 포즈, 죽을 때 추락 | `src/game.js` |
| 키보드·손 입력 공통 충전 처리 / 키 입력 | `src/input-core.js`, `src/keyboard.js` |
| 제목·결과 화면 글자 | `src/main.js` |
| 손동작 판별 | `src/hand-classify.js`, `src/hand.js` |
